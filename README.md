# ESN Labs

ESN Labs 開發者網站，集中列出各 App 的產品頁、隱私權政策與支援資訊。

## 網站結構

- `/`：ESN Labs 首頁
- `/chisha/`：吃啥 App 專頁
- `/chisha/privacy/`：吃啥隱私權政策
- `/assetpilot/`：AssetPilot 資產配置 App 專頁與支援（英文 `/assetpilot/en/`）
- `/assetpilot/privacy/`：AssetPilot 隱私權政策（英文 `/assetpilot/privacy/en/`）
- `/app-ads.txt`：AdMob app-ads.txt（正式爬蟲仍以開發者網域根目錄為準）
